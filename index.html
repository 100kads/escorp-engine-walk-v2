How AI actually works

Harness — the one hub where information and thinking live. On the Challenge a lot of you used Claude as the harness. Same idea.

Connectors — Shopify, Facebook ads, shipping tools, Google Sheets, email… Data in so you can ask anything — and so the system can decide.

Engines — Noah-specific agents that run his systems on top of that harness + connectors.

Platform-agnostic: We install on Grok Bot (easiest; free trial, then ~$100/mo). Claude or another harness still works — same engines, different shell. This guide is Grok-first.
